# v0.3.0 development acceptance

Run `sh tests/test-config.sh` from the repository root on Linux. Parser tests cover ordered output, invalid input and syntax. Run `python3 tests/test-reconcile.py` for isolated mocked reconciliation (requires Python 3 and flock on the test host, not the router). It covers audit, enforcement, ordering, idempotency, invalid config, WAN mismatch, missing/duplicate jumps, missing chains, transaction failures, empty rules, disabled cleanup and foreign references. The mock does not reproduce kernel normalisation or actual firmware concurrency.

Migration: stop scheduler temporarily; back up old router files; install nat-config.awk alongside scripts, replace both config files with localised templates, and install the new engine atomically. Start in AUDIT and verify output before ENFORCE. The old single-word mode file is incompatible. Keep v0.2.0 backup for rollback. No Docker changes.

Hardware tests: repeat original audit/enforce/idempotency/cleanup and firewall restart tests; exercise multiple rules, any protocols, port ranges, empty ruleset, invalid file preservation, and compare canonical iptables -S output (especially protocol-only rules). Test explicit additional addresses only after ISP routing is confirmed. No production claim before tests pass.

Known limitations: WAN mismatch leaves installed rules in place; independent ASUS firewall writers can race; explicit address ownership not checked; no DNAT. Configuration files updated separately, so pause scheduler for coordinated multi-file changes.
